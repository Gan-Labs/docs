Gan-Labs / rule boosting

Rule-following without training

We make a language model follow a rule (be rigorous, don't be sycophantic, be truthful) without any training. The rule is defined only by example pairs. Several approaches then pull on different parts of the model, and all of them are scored on the same held-out test. This page maps each approach onto the model, lists the claims we tested, and says which ones hold.

The paradigm

One objective. For each prompt we have two answers with the same content: one follows the rule, one breaks it. The rule loss is L = NLL(follows) − NLL(breaks), averaged per answer token. Lower L means the model prefers the rule-following answer. The model is never trained on L. We only use it to choose an intervention and to score it.

Several control surfaces. A transformer can be steered in a few places: the prompt, the residual stream at one layer, or the weights. In the residual stream we can push along a few sparse directions (features from a sparse autoencoder, an SAE) or along one dense direction.

Several selection signals. What decides which directions to push? We compare the gradient of L (a Fisher score per SAE feature), the model itself reading each feature's text description, a difference of mean activations (CAA, the standard steering baseline), and random features as a control.

One scorecard. Every intervention is scored on held-out prompts the same way: how much L falls, how much fluency suffers (loss on ordinary Wikipedia text, capped at a 5% rise), whether the effect transfers to differently written answers, and whether it moves the same internal features as simply stating the rule.

The approaches

Prompt

Write the rule into the user message. This is the reference every other approach is measured against.

Sparse SAE boost

Add β × activation × feature direction for k = 8 or 32 SAE features at one layer, on every token. Features are chosen by the Fisher score, by the model itself, or at random.

Dense CAA boost

One direction: the mean activation on rule-following answers minus the mean on rule-breaking ones (Rimsky et al. 2024). No SAE, no feature choice.

Weight edit

Fold the boost into a fixed bias in the weights: a one-shot edit with no optimiser and no runtime hook. Gains are Fisher-scaled or flat.

Where everything sits on the model

Data defines the rule loss. Selection signals turn it into interventions on three control surfaces. Every intervention is read out on the same scorecard. Edge labels name the experiment and claim, and colour shows whether the claim holds (green), partly holds or is exploratory (amber), or fails (red).

Reading the map

  • One path works. Gradient of the rule loss → a handful of SAE features → boost them, at runtime or as a weight edit. On rigor it lowers held-out L about twice as much as stating the rule, survives a change of author on Gemma, and beats random and self-chosen features.
  • The mechanism is not the instruction's. The boost does not move the features that stating the rule moves (C3). It is a different route to the same output preference.
  • The best surface depends on the task. On sycophancy, a strong two-letter preference, the dense CAA direction is the better lever. On TruthfulQA (Gemma-IT, exploratory), the sparse SAE lever helps where both prompting and CAA fail.
  • The SAE is the bottleneck. Only one of seven model/SAE combinations passed the fit check, and the Llama results are weak partly for that reason.
  • The feature cut didn't scale. Requiring a feature's effect to have the same sign on ≥ 50% consistency worked for 60 similar rigor questions but rejected every feature on 300 varied TruthfulQA questions.

Next

  • Replace the fixed feature cut with a sign-consistency test that scales with dataset size, fixed in advance. Rerun sycophancy and TruthfulQA with CAA at its own scale as the standard baseline (≈ $3).
  • Try a better-fitting SAE: Gemma 2 9B with Gemma Scope, or wider Llama SAEs on an 80 GB GPU (≈ $3–5).
  • A human read of 20 rigor answers, boosted vs prompted, to confirm that L reflects real rigor (~30 minutes).
